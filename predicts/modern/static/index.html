BPP Operations Tool
Features & Workflow

        
A quick reference for the tools built into this standalone predictor. Operational colors for trajectories, airspace, and site viability stay fixed even when a launch theme is applied.

      

      

        
Predictions
Run Burst or Float predictions from preset or custom launch sites. Launch times can be now through the model's seven-day forecast window.

        
Optimal Site
Search either the currently selected/custom sites or the full preset list. Airspace is evaluated at the balloon altitude where the path crosses it, with optional ascent-rate sweeping.

        
Launch Weather
Switch Map Mode to Launch Weather to see launch-site wind, gusts, rain, and temperature. Click any launch marker for weather, address details, coordinates, and a direct Ventusky link.

        
Inflation Calculator
The integrated calculator follows the supplied MATLAB model and can automatically feed its burst-height result into Predicts, while preserving a manual burst-altitude option.

        
Live Tracking
Use the separate Live Tracking tab to follow one or more callsigns through the read-only APRS-IS stream and predict from each packet's latitude, longitude, altitude, and time. No API key is required.

        
Airspace & 3D
Special-use and TFR layers remain visible in Basic mode. Advanced mode adds controlled, Class E, reference, drawing, and 3D volume controls.

        
Drawing Tools
Add custom launch points or draw oriented rectangles. Rectangles can be assigned an upper altitude and visualized as 3D volumes.

        
Launch Readiness
Compare selected sites using visible weather, forecast freshness, airspace, landing-risk, ascent-rate, and flight-time evidence.

        
Launch Themes
Use the Launch Theme dropdown to apply Standard, Maryland, Night Launch, Aurora, Country Desert, Summer Beach, or Pride. Themes never alter operational status or trajectory colors.

        
Exports & Sweep
Use the bottom toolbar for KML export, geofence GeoJSON, parameter sweeps, address queries, and map utilities. Click a dotted sweep path to see the exact parameter value.

      

    

  


  

    
Parameter Sweep

    
Run a controlled series of predictions from one launch site. Click a dotted result line to see its exact parameter value.
