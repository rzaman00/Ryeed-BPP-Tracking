BPP Predicts

Run a Burst or Float forecast from a predefined or custom launch point. Float uses BPP's stitched-float method so descent is included.

Live Track pulls the latest position for the three BPP APRS callsigns through the local Python API, keeping the APRS.fi API key out of browser code.

For operational use, always verify the forecast, weather model age, airspace data, NOTAMs/TFRs, and launch authorization independently.
