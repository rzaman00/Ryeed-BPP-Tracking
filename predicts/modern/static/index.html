About BPP Predicts

    
This is the current BPP Predicts interface (v2.3.0), with updated rendering, exact georeferenced landing targets, light/dark themes, responsive behavior, and multi-callsign live APRS prediction.

    
Prediction engine: SondeHub / Tawhiri. Float: BPP stitched-float method (ascent + float + descent). Live tracking: aprs.fi for typed APRS callsigns (defaults: KC3SKW-8, KC3SKW-9, KC3SKW-10). Live predictions start from each station's latest reported latitude, longitude, and altitude.

    
Airspace, school, restaurant, launch-location, and POI overlays are loaded from the existing BPP repository data. Run git lfs pull from the repository root if a layer is unavailable locally.
