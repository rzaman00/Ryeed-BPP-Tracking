BPP Operations Tool
Features & Workflow

        
A quick reference for the tools built into this standalone predictor. Operational colors for trajectories, airspace, and site viability stay fixed even when a launch theme is applied.

      

      

        
Predictions
Run Burst or Float predictions from preset or custom launch sites. Historical dates use archived atmospheric data when available; future predictions remain limited to the model forecast window.

        
Optimal Site
Search either the currently selected/custom sites or the full preset list. Airspace is evaluated at the balloon altitude where the path crosses it, with optional ascent-rate sweeping.

        
Launch Weather
Switch Map Mode to Launch Weather to see launch-site wind, gusts, rain, and temperature. Click a weather marker for wind, gust, rain, and temperature.

        
Inflation Calculator
The integrated calculator follows the supplied MATLAB model and can automatically feed its burst-height result into Predicts, while preserving a manual burst-altitude option.

        
Live APRS
Track one or more APRS callsigns and run live predictions from the latest reported latitude, longitude, altitude, and packet time.

        
Airspace & 3D
Toggle FAA controlled, Class E, special-use, and TFR layers. Switch to 3D to inspect airspace and custom geofence volumes.

        
Drawing Tools
Add custom launch points or draw oriented rectangles. Rectangles can be assigned an upper altitude and visualized as 3D volumes.

        
Launch Themes
Use the Launch Theme dropdown to apply Standard, Maryland, Night Launch, or Aurora colors. Themes never alter red/green/gold status meanings or trajectory colors.

        
Exports & Sweep
Use the bottom toolbar for KML export, geofence GeoJSON, parameter sweeps, address queries, and map utilities. Click a dotted sweep path to see the exact parameter value.

      

    

  


  

    
Parameter Sweep

    
Run a controlled series of predictions from one launch site. Click a dotted result line to see its exact parameter value.
