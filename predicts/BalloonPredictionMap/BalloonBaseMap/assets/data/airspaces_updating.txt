The airspace_class_BCD.geojson file is initially downloaded from https://adds-faa.opendata.arcgis.com/datasets/faa::class-airspace, filtered on the CLASS property to get only B, C, and D class airspaces.
Based on https://en.wikipedia.org/wiki/Airspace_types_(United_States)#Airspace_classes and the previous controlled airspaces file, B, C, and D airspaces seem to be the only classes we really care about. This may or may not be correct.

The airspace_special_use.geojson file is initially downloaded from https://adds-faa.opendata.arcgis.com/datasets/dd0d1b726e504137ab3c41b21835d05b_0, filtered on the TYPE_CODE property to only get MOA, R, and P types.
The previous controlled airspaces file only included restricted airspaces. I've chosen to also include prohibited airspaces and military operation areas.

Both files are separately imported into mapshaper.org and simplified with shape removal prevented. airspace_class_BCD is simplified to 5% and airspace_special_use is simplified to 10%.

Both files are then loaded into a custom Python script to have their coordinates rounded to 6 decimals and their properties filtered to: 
    airspace_class_BCD: "NAME", "CLASS", "LOWER_VAL", "LOWER_UOM", "LOWER_CODE", "UPPER_VAL", "UPPER_UOM", "UPPER_CODE"
    airspace_special_use: "NAME", "TYPE_CODE", "LOWER_VAL", "LOWER_UOM", "LOWER_CODE", "UPPER_VAL", "UPPER_UOM", "UPPER_CODE", "TIMESOFUSE"
